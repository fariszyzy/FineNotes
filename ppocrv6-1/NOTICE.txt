FineNotes on-device OCR models, set "ppocrv6-1" (data only, no code).

Files
  PP-OCRv5_mobile_det_infer.ort   PaddleOCR PP-OCRv5 mobile text detector (DBNet), ONNX Runtime
                                  format. Unchanged from the file published in the npm package
                                  pdfmarkdown-ppocrv5-models 1.0.0.
  PP-OCRv6_tiny_rec.ort           PaddleOCR PP-OCRv6 tiny text recogniser (SVTR, CTC), ONNX
                                  Runtime format. Unchanged from
                                  recognition/ort/PP-OCRv6_tiny_rec.ort of
                                  https://github.com/PT-Perkasa-Pilar-Utama/ppu-paddle-ocr-models
  ppocrv6_tiny_dict.txt           Its character dictionary (unchanged, same repository).

Why they are here
  FineNotes downloads them on first use, each pinned by exact size and SHA-256 in
  src/recognition/ocr/ocr-model.ts of the main branch, from raw.githubusercontent.com (this
  branch), so the download needs neither a Git LFS bandwidth budget nor Hugging Face.
