FineNotes on-device OCR models, set "ppocrv6-medium-1" (data only, no code).

Files
  PP-OCRv6_medium_rec.ort   PaddleOCR PP-OCRv6 medium text recogniser (SVTR, CTC), ONNX Runtime
                         format. Unchanged from recognition/ort/PP-OCRv6_medium_rec.ort of
                         https://github.com/PT-Perkasa-Pilar-Utama/ppu-paddle-ocr-models
  ppocrv6_dict.txt       Its character dictionary (unchanged, same repository).

The text detector (PP-OCRv5_mobile_det_infer.ort) is shared with the set "ppocrv6-1" and is not repeated here.

Why they are here
  FineNotes downloads them on first use, each pinned by exact size and SHA-256 in
  src/recognition/ocr/ocr-model.ts of the main branch, from raw.githubusercontent.com (this
  branch), so the download needs neither a Git LFS bandwidth budget nor Hugging Face.
